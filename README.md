# yuque-exporter · 语雀本机备份采集器

通过浏览器已登录的语雀会话，将自己拥有的已发布文档、图片和附件保存到本机。支持单篇采集、可恢复的批量采集和单个 ZIP 下载。

当前版本：0.5.0。扩展采用 Manifest V3，无第三方运行依赖，无需构建。适用于支持相关扩展 API 的 Edge、Chrome 桌面浏览器；不同浏览器版本仍需实际验证。

## 功能

- 盘点个人知识库、已发布文档和目录。
- 默认选择全部未完成文章，同时采集 3 篇，可调整为 1～4 篇。
- 每个采集页面最多同时下载 4 个图片或附件资源。
- 支持暂停、继续及仅重试失败文章，完成的文章保存在浏览器 IndexedDB 中。
- 批量结果下载为一个 ZIP，包含清单和成功文章的 JSON。
- 可直接下载 Markdown ZIP，包含文章目录、本地图片附件、转换报告，以及包内文章间的相对链接。
- 采集前后复核文章版本，遇到正文变化或资源失败时保留失败状态。

本仓库包含浏览器采集器和离线 Markdown 转换器。原始采集包适合完整备份及后续导入，Markdown 包适合直接阅读和迁移。工具不自动发布网站。

## 安装

1. 下载仓库 ZIP 并解压，或使用 Git 克隆仓库。
2. 在 Edge 打开 `edge://extensions`，或在 Chrome 打开 `chrome://extensions`。
3. 启用“开发人员模式”，选择“加载解压缩的扩展程序”。
4. 选择仓库中的 `browser-collector` 目录，该目录直接包含 `manifest.json`。
5. 正常登录语雀。

更新时，在扩展管理页重新加载同一目录，再重新打开采集页面。数据库名称和结构与 0.2.0 兼容；同一扩展身份下已有任务可继续。换目录安装或卸载后重装可能产生不同的存储环境，操作前先下载已有结果。

## 批量采集

1. 点击扩展图标，选择“打开目录盘点与批量采集”。
2. 点击“盘点目录 / 继续盘点”。工具读取自有知识库的文档列表和目录。
3. 保持默认全选，点击“开始 / 继续采集”。取消全选后可限制每轮检查 1～100 篇。
4. 如需暂停，点击“完成正在采集的文章后暂停”。工具停止安排新文章，等待已开始的文章处理完。
5. 使用“重试失败文章”重试失败项。
6. 点击“下载 Markdown（ZIP）”直接保存文章和图片，或点击“下载本地采集包（ZIP）”保存原始 JSON。默认保存到浏览器下载目录的 `yuque-migration/` 下，同名文件会自动增加后缀。

运行时保持批量标签页打开。切换标签页不影响采集；关闭页面或浏览器会中断正在处理的文章，重新打开后可继续未完成任务。

日常更新时，点击“新建增量任务”，等待目录盘点完成，再点击“开始 / 继续采集”。新增、版本变化、此前失败或缺少可验证版本信息的文章会进入队列。对于可确认已发布且版本信息一致的文章，插件复用已有正文和附件。如果需要重新下载所有资源，选择“新建全量任务”。

当目录接口没有返回修改状态时，插件会读取文章详情，核对身份、版本和正文后再决定是否复用，确认一致的文章无需重新下载图片和附件。详情读取失败会保留原任务，并提示重新盘点。

新的盘点成功后才切换任务。通过“下载任务”选择当前或历史任务，均可单独导出 ZIP。当前目录已移除的文章仍可从当时成功采集的历史任务中导出。历史正文会持续占用浏览器存储。

## 单篇采集

在当前标签页打开自己文章的语雀阅读页，点击扩展图标，再点击“采集当前文章”。保持弹窗打开直到保存提示出现。下载文件名为 `yuque-sample-<文章ID>.json`。

## Markdown 阅读包

批量页的“下载 Markdown（ZIP）”使用已保存在本机的成功快照，无需重新采集或访问语雀。可以选择当前或历史任务。解压后打开 `README.md` 查看文章目录。

```text
README.md
export-report.json
知识库名称-ID/
  文章标题-ID.md
assets/
  内容哈希.png
```

文件名中的 ID 避免同名文章冲突。图片和附件按内容去重，文章引用本地资源，包内文章链接改为相对路径。移动备份时应保留整个目录结构。原知识库的目录树保存在原始采集包中，Markdown 包按知识库分组，不复刻全部目录层级。

支持常见标题、段落、列表、代码块、普通表格、图片、附件、折叠内容和公式。公式输出 LaTeX，需使用支持数学公式的 Markdown 阅读器。字体、颜色和原网页布局不保证还原。

未知卡片、合并单元格、嵌入内容、缺失图片或无效资源会停止 Markdown 下载并提示原因，原始采集结果仍保留。未采集或失败文章会列入 `export-report.json`，不会被默认为转换成功。外部文件链接及缺少目标的语雀链接保留来源地址并给出提示；报告 `complete` 只有在没有未完成项和提示时才为 `true`。

## 输出格式

原始采集 ZIP 解压后直接包含：

```text
inventory.json
doc-<知识库ID>-<文章ID>.json
...
```

| 文件 | 内容 |
| --- | --- |
| `inventory.json` | schema、任务编号、账号标识、知识库和文档目录、pending/failed/done 状态、错误信息 |
| 文章 JSON | schema、采集时间、账号和知识库标识、文章元数据、原始正文、资源 URL 到 Base64 内容的映射 |

批量清单的 `kind` 为 `yuque-browser-batch`，文章包为 `yuque-browser-sample`，目前 `schema` 均为 `1`。批量文章带有对应 `run_id`；单篇模式不带批量任务编号。

只有成功文章会写入 ZIP，但失败和待采集文章仍保留在清单中。因此下载成功不等于全部文章备份完成。读取方应检查每个任务状态，按知识库和文章 ID 匹配正文，并核对任务和账号身份。

## 版本与范围限制

仅处理可确认所有权的个人知识库和普通文档。团队或协作知识库、加密文档、特殊格式以及从未发布的草稿不在支持范围内。

公开版的 `browser-collector/verified-versions.json` 固定为空数组，不包含任何真实文章记录。存在未发布修改、缺少必要版本信息或无法独立确认已发布正文时，采集会失败并提示原因。不要为了通过检查而发布尚未准备公开的修改。

源码保留按本地核验记录匹配正文哈希的机制，用于测试和私有定制。维护公开仓库时必须保持记录为空；不要将自己的核验记录或正文哈希提交到仓库。

- 单资源上限为 20 MiB，单篇资源 Base64 编码总量上限为 80 MiB。
- 普通外站链接保留原地址；图片、附件卡片及受支持站点的文件链接需要成功下载。
- ZIP 使用浏览器原生 raw DEFLATE；不支持时退回不压缩的 ZIP。压缩包仍占用本机内存和 Blob 存储，且受 ZIP32 大小限制。
- 接口采用语雀网页内部只读接口，服务端变动可能导致盘点或采集失败。
- 并发上限、暂停恢复、存储失败和 ZIP 下载已有合成测试覆盖。真实速度受网络、资源大小和服务端限制影响。

## 权限与数据

| 权限或域名 | 用途 |
| --- | --- |
| `activeTab` | 用户点击扩展后识别当前文章地址 |
| `downloads` | 保存采集包并检查下载是否完成 |
| `www.yuque.com` | 读取当前账号、自有知识库、目录和正文 |
| `cdn.nlark.com`、`cdn.yuque.com` | 下载正文引用的图片和附件 |

没有 `cookies` 权限，不读取或导出 Cookie 值。浏览器按请求站点携带登录会话。插件没有自建上传服务、遥测或网站发布操作。详细数据说明见 [PRIVACY.md](PRIVACY.md)。

下载结果包含账号标识、可能私密的正文、资源地址和附件内容，属于用户的私有备份，不应作为源码上传。仓库 `.gitignore` 排除常见采集输出，但提交前仍应检查暂存区。

## 开发与测试

安装 Node.js 22 或更高版本，在仓库根目录执行：

```sh
npm test
```

不需要执行 `npm install`。测试只使用合成数据，不访问真实账号。测试覆盖资源和版本校验、队列恢复、并发上限、串行保存、暂停、存储失败、ZIP 下载与取消、Markdown 转换与资源打包，以及公开文件检查。另可在浏览器打开 `tests/markdown-browser.html`，验证真实 HTML 解析器的转换行为。

```text
browser-collector/      可直接加载的扩展
tests/                  合成测试与公开文件检查
scripts/run-tests.cjs   测试入口
package.json            测试命令
PRIVACY.md              数据与权限说明
```

修改后重新加载扩展并手动验证页面。报告问题时请提供扩展版本、浏览器版本、操作步骤和经过脱敏的错误文字，不要附带真实采集包、登录信息或带签名参数的资源链接。
